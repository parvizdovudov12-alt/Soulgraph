Функциональные требования (важно):
 • Основной компонент — интерактивный ценовой график, визуально копирующий стиль и поведение графика на Bybit (с свечами/лайном, зумом, скроллом, hover-инфо, сеткой). Для реализации используй библиотеку lightweight-charts (или другой открытый аналог TradingView).
 • График отображает временную шкалу (дни/часы) и одно агрегированное значение «жизненного индекса» по умолчанию (Y-ось).
 • На графике должны появляться маркеры (аннотации) для новостей: две кнопки на UI — «Положительная новость» и «Отрицательная новость». При нажатии открывается модальное окно для ввода текста новости и выбора времени (по умолчанию — сейчас).
 • Положительная новость: маркер/стрелка и подпись отображаются зелёным и при добавлении увеличивают локально значение индекса на +X (см. правила ниже).
 • Отрицательная новость: маркер/стрелка и подпись — красные, уменьшают индекса на −X.
 • График учитывает 4 состояния пользователя: Душевное, Физическое, Моральное, Финансовое. Каждое состояние — отдельная временная серия (скрываемая/включаемая через чекбоксы) и влияет на агрегированный индекс по весам. По умолчанию агрегированный индекс = взвешенная сумма состояний. Весы задаются в настройках пользователя (простой UI: четыре input[type=number] от 0 до 1, сумма автоматически нормируется).
 • При добавлении новости пользователь указывает: тип (полож/отриц), влияние по каждому из 4 состояний (например +0.1 Душевное, −0.05 Финансовое и т.д.) — эти правки применяются в тот таймпоинт и отражаются на соответствующих сериях. Маркер показывает короткий текст (тултип) и при клике — развернутое модальное с полной информацией.
 • График динамически перерисовывается и поддерживает анимацию (плавный переход) при изменении данных.
 • Простой офлайн-режим: локальное сохранение сессии в sqlite/lowdb (или localStorage + optional API sync).

 • Кнопки «Положительная новость» — зелёные, «Отрицательная новость» — красные. На графике маркеры должны быть цветом новости.
 • Панель справа: чекбоксы для включения/отключения серий (Душевное, Физическое, Моральное, Финансовое), sliders/inputs для весов, кнопки добавления новости.
